# Project Rules

## General

- Build production-ready code only.
- Follow clean architecture.
- Reuse existing components and utilities.
- Keep code modular and maintainable.
- Never duplicate code.
- Follow the existing project structure.

---

## Frontend

Always delegate ALL frontend work to the `frontend-pro-max` agent.

Frontend includes:

- UI
- UX
- React
- Next.js
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Responsive Design
- Accessibility
- Design System
- Component Development

The `frontend-pro-max` agent should:

1. Search the 21st.dev MCP before creating any UI.
2. Reuse production-ready components whenever possible.
3. Use the installed UI/UX Pro Max Skill if available.
4. If the skill is unavailable, apply the same UI/UX principles internally.
5. Use Context7 when documentation is needed.
6. Use Framer Motion for meaningful animations only.
7. Build premium-quality interfaces inspired by Apple, Linear, Stripe, Vercel and Notion.
8. Review spacing, typography, hierarchy, accessibility, responsiveness and animations before finishing.

Never generate generic UI.

---

## Backend

Do not use the frontend agent for backend work.

Keep backend focused on:

- APIs
- Authentication
- Database
- Business Logic
- Validation
- Performance
- Security

---

## Final Quality Check

Before completing any task verify:

- Production-ready
- Responsive
- Accessible
- Performant
- Clean code
- Reusable
- Consistent
